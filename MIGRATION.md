# Parcours omnicanal 1re MCV A

## Reprendre un carnet existant
1. Ouvrir l’ancienne application Google dans le navigateur utilisé par l’élève.
2. Cliquer sur « Exporter mon carnet (.json) » et conserver le fichier.
3. Ouvrir le nouveau parcours GitHub Pages et cliquer sur « Importer un carnet ».
4. Vérifier les réponses et les cases de progression avant de quitter l’ancienne application.

Le contenu du parcours est conservé. Les données restent dans le navigateur ; GitHub ne centralise pas les réponses. Pour changer de PC ou de navigateur, utiliser export/import.
